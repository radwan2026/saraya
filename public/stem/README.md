# 🧪 ألعاب العلوم — منصة محاكاة STEM للأطفال (8–12 سنة)

منصة تعليمية تفاعلية ثنائية اللغة (عربي / English) يتعلم فيها الطفل عبر ثلاث مراحل لكل درس:

1. **التجميع** — يسحب القطع من «صندوق القطع» ويثبّتها في مكانها على «طاولة العمل» (سحب وإفلات بالفأرة، أو سحب/نقر باللمس على الأجهزة اللوحية).
2. **المحاكاة** — زر «تشغيل» يحرّك المجسّم بحركات CSS (مراوح تدور، مصابيح تومض، مدارات، مكابس هيدروليكية…) مع شريط سرعة وسلسلة «رحلة الطاقة».
3. **الاختبار** — نافذة أسئلة اختيار من متعدد؛ الإجابة الصحيحة تضيف نقاط خبرة (XP) مع قصاصات احتفالية.

## التشغيل

- **أسهل طريقة:** انقر نقراً مزدوجاً على `index.html` ليفتح في المتصفح. لا حاجة لـ `npm install`.
- **أو بخادم محلي:** من داخل هذا المجلد شغّل `npm start` ثم افتح `http://localhost:8080`.
- تحتاج اتصالاً بالإنترنت لتحميل Tailwind و Alpine.js والخط من CDN.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الواجهة كاملة: لوحة التحكم، لوحة الصدارة، مساحة العمل، نافذة الاختبار |
| `js/lessons.js` | **بيانات الدروس العشرة بصيغة JSON** + رسومات SVG لكل قطعة |
| `js/app.js` | منطق Alpine.js: الحالة، السحب والإفلات، نقاط الخبرة، المستويات، الحفظ |
| `css/styles.css` | حركات المحاكاة (تعمل فقط عند وجود الكلاس `.powered`) |
| `img/` | صور المجسّمات الحقيقية |

## نظام النقاط

| الحدث | XP |
|---|---|
| إكمال التجميع | 30 |
| تشغيل المحاكاة | 20 |
| إجابة صحيحة من أول محاولة | 50 (+ نجمة ⭐) |
| إجابة صحيحة بعد محاولة خاطئة | 20 |

كل 250 نقطة = مستوى جديد. النقاط تُمنح مرة واحدة لكل خطوة، ويُحفظ التقدم في المتصفح (`localStorage`).
لوحة الصدارة نموذج واجهة فقط، وتُصفَّر «نقاط هذا الأسبوع» تلقائياً كل يوم أحد.

## إضافة درس جديد

انسخ أي كائن داخل مصفوفة `LESSONS` في `js/lessons.js` وعدّل: العنوان، القطع (`parts` مع `slot` و`art`)، سلسلة الطاقة (`flow`)، الشرح، والأسئلة (`quiz`).
لا حاجة لتعديل `app.js` — البطاقة ومساحة العمل والاختبار تُبنى تلقائياً من البيانات.
لإضافة حركة جديدة: أعطِ عنصر SVG كلاساً (مثل `spin`) وعرّف حركته في `styles.css` تحت `.powered`.
