# 🧭 منظومة الرحالة — لإدارة حسابات مكاتب السياحة والسفر

منظومة محاسبية لمكاتب السياحة والسفر بواجهة تشبه برامج سطح المكتب (قوائم علوية، شريط أدوات، نوافذ متعددة)،
تعمل في المتصفح على جهاز المكتب أو على الشبكة المحلية، وتحفظ البيانات في ملف قاعدة بيانات SQLite واحد.

---

## ✨ الخدمات

| القائمة | الشاشات |
|---|---|
| **جديد** | فاتورة جديدة (F2)، إيصال قبض (F3)، إيصال دفع (F4)، إشعار مدين/دائن، عميل جديد، مزود جديد |
| **الخزينة** | ملف الحركة، أسعار العملات، إيصال قبض، إيصال دفع، إشعارات التسوية (إشعار مدين - Debit Note، إشعار دائن - Credit Note، قائمة بالإشعارات)، فواتير (إنشاء، قائمة الفواتير، تقرير التذاكر)، عرض حساب (F5)، قائمة المقبوضات والمدفوعات، حركة الخزينة |
| **بحث** | بحث شامل باسم المسافر أو رقم التذكرة/المستند أو رقم الفاتورة أو اسم الحساب أو الهاتف (Ctrl+F)، دليل الحسابات |
| **تقارير** | المبيعات والأرباح (حسب الخدمة/المزود/الناقل/العميل/اليوم)، تقرير التذاكر والخدمات، أرصدة العملاء والوكلاء والمزودين، ميزان المراجعة، حركة الخزينة |
| **مراجعة** | اعتماد المستندات (المستند المراجَع يُقفل ضد التعديل والحذف)، إلغاء المراجعة للمدير |
| **خدمات ← ضبط** | إضافة مزود، إضافة عميل، البيانات المصرفية، إضافة خدمة، دليل الحسابات، New Sub Agent (وكيل فرعي)، الخزائن والمصارف، حسابات المصروفات، سياسات البيع، إضافة شركة ناقلة، إضافة مدينة، إضافة دولة، عمولات خاصة، العملات الأجنبية، Import From Excel |
| **خدمات** | المشغلين (المستخدمين والصلاحيات)، تغيير كلمة المرور، المظهر العام وبيانات المكتب، ترخيص النظام، حول النظام |

### الفاتورة
مطابقة لشاشة «إنشاء فاتورة جديدة»: الجهة، السادة، ملاحظات، رقم الفاتورة، التاريخ، العملة وسعر الصرف،
بنود (التاريخ، الخدمة، المزود، الناقل، رقم المستند/التذكرة، الاسم، البيان، التكلفة، القيمة، خدمات)،
نسبة خدمات % وتخفيض %، إظهار قيمة الخدمات، وإظهار الحساب البنكي في نهاية الفاتورة عند الطباعة.

### المحاسبة (قيد مزدوج تلقائي)
- **الفاتورة:** مدين العميل بالإجمالي، دائن كل مزود بتكلفة بنده، والفرق ربح في حساب «إيرادات الخدمات».
- **إيصال القبض:** مدين الخزينة/المصرف، دائن الحساب. **إيصال الدفع:** العكس.
- **إشعار مدين / دائن:** تسوية رصيد الحساب مقابل حساب «التسويات».
- **العملات:** كل مستند يحفظ عملته وسعر صرفه، والأرصدة والتقارير بالدينار الليبي.
- **سياسات البيع والعمولات الخاصة:** عند إدخال التكلفة يقترح النظام سعر البيع تلقائياً.

كل شاشة تقارير فيها **طباعة** و**تصدير إلى Excel (CSV)**، والفواتير والإيصالات تُطبع بترويسة المكتب.

## 🚀 التشغيل

المتطلبات: **Node.js الإصدار 22.13 أو أحدث** (يفضل نسخة LTS الحالية من [nodejs.org](https://nodejs.org)).

```bash
cd rahhala
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3100**

- المستخدم الافتراضي: **admin** وكلمة المرور: **admin** — غيّرها فوراً من «خدمات ← تغيير كلمة المرور».
- لاستخدامها من أجهزة أخرى في المكتب افتح `http://<عنوان-جهاز-الخادم>:3100`.
- لتغيير المنفذ: `PORT=8080 npm start` — ولتغيير مكان قاعدة البيانات: `RAHHALA_DB=/path/office.db npm start`.

### النسخ الاحتياطي
كل البيانات في الملف `rahhala/data/rahhala.db`. أوقف البرنامج وانسخ هذا الملف (والملفات المرافقة له `-wal`/`-shm` إن وجدت) إلى مكان آمن.

### الاستيراد من Excel
من «خدمات ← ضبط ← Import From Excel»: انسخ الأعمدة من Excel بالترتيب
(الاسم، الهاتف، البريد، العنوان، الرصيد الافتتاحي، رقم الحساب اختياري) والصقها، أو اختر ملف CSV.
