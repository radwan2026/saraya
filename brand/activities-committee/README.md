# دليل هوية لجنة الأنشطة

افتح `index.html` في المتصفح لعرض الدليل كاملًا.

## الملفات في `assets/`

| الملف | الاستخدام |
|---|---|
| `logo-color.png` | النسخة الأساسية الملوّنة (خلفية شفافة) |
| `logo-white.png` | النسخة البيضاء للخلفيات الخضراء والداكنة |
| `logo-dark.png` | النسخة أحادية اللون |
| `logo-symbol.png` | الرمز وحده دون الاسم |
| `logo-wordmark.png` | اسم اللجنة وحده (لتكوين النسخة الأفقية) |
| `mockup-*.jpg`, `pattern.jpg` | أمثلة التطبيقات وأسلوب الصور |

النسخ مستخرجة من ملف الشعار الأصلي (JPG بدقة 1080 بكسل). للطباعة الكبيرة يُفضّل الرجوع إلى ملف المصمم المتجه (AI / SVG / PDF).
