# Shift Academy — موقع الأكاديمية

صفحة هبوط ثابتة (HTML/CSS/JS بدون أي أدوات بناء) مستوحاة من هيكل موقع shiftacademy.ly،
ومطبّقة على دليل الهوية البصرية لـ Shift Academy.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً:

```bash
cd shift-academy && python3 -m http.server 8080
```

## الهوية المطبّقة
| العنصر | القيمة |
|---|---|
| كحلي الثقة (أساسي ~60%) | `#27345D` |
| ذهبي الارتقاء | `#FFB11A` |
| الذهبي العميق | `#BC8A33` |
| ذهبي الكلمة | `#E3A025` |
| رمادي الطيّة | `#BCBCBC` |
| الأبيض | `#FFFFFF` |
| خط العناوين | Cairo |
| خط النصوص | IBM Plex Sans Arabic |
| الكلمة اللاتينية | Nunito Sans Italic |

- `assets/logo-mark.svg`: رمز الشعار (S + A مع السهم) كملف SVG، ويُستخدم أيضاً كأيقونة الموقع.
- الدورات تُعرض من مصفوفة `COURSES` في `script.js` — عدّلها لإضافة أو حذف دورات.
- نموذج التسجيل يعمل في الواجهة فقط؛ اربطه بخدمة بريد أو API لاستقبال الطلبات فعلياً.
