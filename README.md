# 🎮 لعبة الضوء الأحمر / الضوء الأخضر — لبث تيك توك المباشر

لعبة تفاعلية مستوحاة من «لعبة الحبار»، يشارك فيها متابعوك مباشرةً من تعليقات البث.
تعمل على جهازك كخادم Node.js صغير، وتُعرض كصفحة ويب عمودية (9:16) تضيفها في **TikTok LIVE Studio** أو **OBS**.

---

## 📜 قواعد اللعبة

1. **الانضمام:** يكتب المتابع رقماً من **1 إلى 10** في التعليقات (يقبل الأرقام العربية مثل ٤ أيضاً).
2. عند الانضمام تظهر **بطاقة شخصية** على الشاشة فيها اسمه وصورته والرقم الذي اختاره، ويظهر لاعبه على خط البداية.
3. في كل جولة تلتفت **الدمية** وتختار رقماً عشوائياً من 1 إلى 10:
   - من كان رقمه **أكبر من أو يساوي** رقم الدمية ← **يخرج من اللعبة** ❌
   - من كان رقمه **أقل** من رقم الدمية ← **يتقدّم بعدد خطوات يساوي رقمه** ✅
4. بين الجولات (مرحلة **الضوء الأخضر**) يستطيع اللاعبون الأحياء **تغيير رقمهم** بكتابة رقم جديد.
5. **أول من يصل إلى خط النهاية يفوز** وتظهر شاشة الفوز باسمه وصورته. إذا وصل أكثر من لاعب في نفس الجولة يفوز الأبعد مسافةً، وعند التعادل الأسبق انضماماً.
6. إذا خرج الجميع تظهر شاشة «خرج الجميع» وتبدأ لعبة جديدة تلقائياً.

> 💡 **الاستراتيجية:** الرقم الكبير يقدّمك أسرع لكنه أخطر، والرقم الصغير آمن لكنه بطيء!

---

## 🧰 المتطلبات

- **Node.js الإصدار 20 أو أحدث** — حمّله من [nodejs.org](https://nodejs.org) (اختر نسخة LTS).
- **TikTok LIVE Studio** أو **OBS Studio** للبث.
- حساب تيك توك **يبث مباشرة** وقت تشغيل اللعبة (للعب الحقيقي). وضع التجربة لا يحتاج بثاً.

للتأكد من تثبيت Node.js افتح الطرفية (Terminal / موجه الأوامر CMD) واكتب:

```bash
node -v
```

يجب أن يظهر رقم إصدار مثل `v20.x.x` أو أعلى.

## 🚀 التشغيل خطوة بخطوة

### الخطوة 1: تنزيل المشروع

نزّل المشروع (زر **Code ← Download ZIP** في GitHub ثم فك الضغط)، أو باستخدام git:

```bash
git clone https://github.com/radwan2026/saraya.git
cd saraya
```

### الخطوة 2: تثبيت المكتبات

داخل مجلد المشروع شغّل مرة واحدة فقط:

```bash
npm install
```

### الخطوة 3: جرّب اللعبة بوضع التجربة (بدون بث)

```bash
npm run demo
```

ثم افتح المتصفح على:

- **شاشة اللعبة:** <http://localhost:3000>
- **لوحة التحكم:** <http://localhost:3000/admin>

سينضم لاعبون وهميون تلقائياً وتبدأ الجولات، لتشاهد اللعبة كاملة حتى شاشة الفوز.
من لوحة التحكم يمكنك أيضاً كتابة تعليق يدوي (اسم + رقم) لتجربة الانضمام بنفسك.

### الخطوة 4: التشغيل مع البث الحقيقي

1. ابدأ البث المباشر على تيك توك أولاً.
2. شغّل الخادم مع اسم حسابك (بدون @):

   ```bash
   npm start -- --user=اسم_حسابك
   ```

   أو شغّل `npm start` فقط، ثم افتح لوحة التحكم <http://localhost:3000/admin> واكتب اسم الحساب واضغط **اتصال**.

   يمكنك أيضاً كتابة اسم الحساب بشكل دائم في ملف `config.js` في الحقل `tiktokUsername`.
3. عندما تظهر حالة **متصل** في لوحة التحكم، أصبحت تعليقات بثك تُقرأ مباشرة.

> إذا لم يكن الحساب في بث مباشر، سيعيد الخادم المحاولة تلقائياً كل 10 ثوانٍ.

### الخطوة 5: إضافة اللعبة إلى البث

#### في TikTok LIVE Studio
1. اضغط **Add Source / إضافة مصدر** ← اختر **Link / رابط** (أو Browser).
2. الصق الرابط: `http://localhost:3000`
3. اضبط الحجم على **1080 × 1920** (عمودي).
4. كبّر المصدر ليملأ الشاشة أو ضعه بالحجم الذي تريده.

#### في OBS Studio
1. في **Sources / المصادر** اضغط **+** ← **Browser / متصفح**.
2. الرابط: `http://localhost:3000`
3. العرض **1080** والارتفاع **1920**.
4. فعّل خيار **Control audio via OBS** إذا أردت التحكم بصوت اللعبة.
5. اجعل لوحة البث عمودية من **Settings ← Video**: الدقة الأساسية `1080x1920`.

#### خيارات الرابط
| الرابط | الوصف |
|---|---|
| `http://localhost:3000` | الشاشة العادية بخلفية داكنة |
| `http://localhost:3000/?transparent=1` | خلفية شفافة لوضع اللعبة فوق الكاميرا |
| `http://localhost:3000/?sound=0` | بدون مؤثرات صوتية |
| `http://localhost:3000/?transparent=1&sound=0` | الخياران معاً |

## 🕹️ لوحة التحكم

افتحها في متصفحك العادي (لا تضفها للبث): <http://localhost:3000/admin>

- **اتصال / قطع:** ربط اللعبة بحساب تيك توك.
- **ابدأ اللعبة الآن:** يبدأ الجولة الأولى فوراً دون انتظار العد التنازلي.
- **تخطّي المرحلة:** ينتقل للمرحلة التالية فوراً.
- **لعبة جديدة:** يمسح اللاعبين ويعيد الردهة.
- **وضع التجربة:** تشغيل/إيقاف اللاعبين الوهميين، أو إضافة عدد محدد منهم.
- **محاكاة تعليق يدوي:** اكتب اسماً ورقماً لتجربة الانضمام.
- جدول اللاعبين، آخر التعليقات، وآخر الفائزين.

## ⚙️ الإعدادات (`config.js`)

| الإعداد | الافتراضي | الوصف |
|---|---|---|
| `tiktokUsername` | `''` | اسم حساب تيك توك |
| `signApiKey` | `''` | مفتاح Euler Stream (اختياري، انظر حل المشاكل) |
| `port` | `3000` | منفذ الخادم |
| `demo` | `false` | تشغيل وضع التجربة تلقائياً |
| `game.trackLength` | `25` | عدد الخطوات حتى خط النهاية |
| `game.dollMin` / `game.dollMax` | `1` / `10` | مدى رقم الدمية (اجعل `dollMin: 2` كي لا يخرج الجميع عند اختيار 1) |
| `game.minPlayers` | `2` | أقل عدد لاعبين لبدء العد التنازلي |
| `game.maxPlayers` | `200` | أقصى عدد لاعبين (0 = بلا حد) |
| `game.allowChangeNumber` | `true` | السماح بتغيير الرقم بين الجولات |
| `game.allowLateJoin` | `false` | السماح بالانضمام بعد بدء اللعبة |
| `game.lobbySeconds` | `30` | مدة الانضمام بعد اكتمال الحد الأدنى |
| `game.chooseSeconds` | `10` | مدة الضوء الأخضر لتغيير الأرقام |
| `game.dollTurnSeconds` | `3` | مدة التفات الدمية |
| `game.resultSeconds` | `5` | مدة عرض النتيجة |
| `game.winnerSeconds` | `12` | مدة شاشة الفوز |
| `game.autoStart` | `true` | بدء اللعبة تلقائياً (أو `false` للبدء من لوحة التحكم فقط) |
| `demoBots.count` | `14` | عدد اللاعبين الوهميين في كل لعبة |

خيارات سطر الأوامر (تتقدّم على الملف):

```bash
node server.js --user=اسم_الحساب --port=3000 --demo --key=مفتاح_Euler
```

## 🔄 مراحل اللعبة

```
الردهة (انضمام + عد تنازلي)
   ↓
الدمية تلتفت 🔴 وتختار رقماً
   ↓
النتيجة: خروج (رقم ≥ الدمية) / تقدّم (رقم < الدمية)
   ↓
هل وصل أحد لخط النهاية؟ ── نعم ──→ شاشة الفوز 🏆 ──→ لعبة جديدة
   │ لا
هل خرج الجميع؟ ── نعم ──→ «خرج الجميع» 💀 ──→ لعبة جديدة
   │ لا
الضوء الأخضر 🟢 (تغيير الأرقام) ──→ الدمية تلتفت مرة أخرى ...
```

## 🛠️ حل المشاكل

| المشكلة | الحل |
|---|---|
| `npm` غير معروف | ثبّت Node.js ثم أعد فتح الطرفية |
| «ليس في بث مباشر الآن» | ابدأ البث أولاً وتأكد من كتابة اسم الحساب بدون @ وبشكل صحيح |
| خطأ فيه `sign` أو `rate limit` | أنشئ مفتاحاً مجانياً من [eulerstream.com](https://www.eulerstream.com) وضعه في `signApiKey` داخل `config.js` أو مرّره بـ `--key=` |
| `EADDRINUSE` (المنفذ مستخدم) | أغلق النسخة الأخرى من الخادم أو استخدم `--port=3001` وعدّل الرابط |
| الصور الشخصية لا تظهر | تظهر صورة بديلة بالحرف الأول تلقائياً؛ تأكد من اتصال الإنترنت |
| لا يوجد صوت في OBS | فعّل **Control audio via OBS** في إعدادات مصدر المتصفح |
| الشاشة لا تتحدث | تأكد أن الخادم ما زال يعمل في الطرفية، ثم حدّث المصدر (Refresh) |

> ⚠️ مكتبة `tiktok-live-connector` غير رسمية وتعتمد على واجهات تيك توك الداخلية، لذا قد تتوقف أحياناً عند تغيير تيك توك لأنظمته. حدّثها عندها بالأمر: `npm update tiktok-live-connector`

# 🐪 المؤمن الصغير — لعبة تعليمية ثقافية

لعبة لوحية (مسار متعرج) من 2 إلى 4 لاعبين عن الخلفاء الراشدين ومكارم الأخلاق، موجودة في مجلد `al-moumen/`.
افتح الملف `al-moumen/index.html` في المتصفح مباشرة (لا تحتاج خادماً). الشرح الكامل داخل اللعبة من زر «شرح اللعبة».

- `al-moumen/data.js`: البطاقات (14 حظ، 50 سؤال صح/خطأ، 20 تحدٍّ، 18 كنز) — يمكن تعديلها أو الإضافة إليها.
- `al-moumen/game.js`: الرقعة والقواعد. مواقع الكنوز والسلالم والزوابع في الثوابت `TREASURE` و`LADDERS` و`TORNADO` و`BONUS`.
