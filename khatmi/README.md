# ختمي — My seal

تطبيق ليبي محلي لتصميم **الأختام الاحترافية بالذكاء الاصطناعي** باللغتين العربية والإنجليزية، مع محفظة تُشحن برصيد المكالمات من **المدار** أو **ليبيانا**، وتسعير تلقائي حسب عدد الحروف والأيقونة.

## ✨ المزايا

| الميزة | التفاصيل |
|---|---|
| تصميم بالذكاء الاصطناعي | يدخل العميل الاسم الشخصي أو اسم الشركة (عربي / إنجليزي / الاثنين) والنشاط والمدينة والشعار، فيقترح التطبيق 4 تصاميم مختلفة. يستخدم **Claude** عند إضافة مفتاح API، وإلا يعمل بمصمم ذكي محلي. |
| التصميم المباشر | معاينة فورية أثناء التعديل: الشكل (دائري، بيضاوي، مستطيل، مستطيل منحني، سداسي)، المقاس بالملم، لون الحبر، 6 أنواع إطارات، 4 خطوط عربية و 6 إنجليزية، أيقونات مدمجة أو شعار العميل، الفواصل، حجم النص وتباعده، ومظهر "حبر حقيقي". |
| الشعار | يرفع العميل شعاره (PNG / JPG / SVG / WEBP) ويمكن تحويله تلقائياً للون الحبر ليبدو كختم حقيقي. |
| ملفات قابلة للتعديل | بعد الشراء: **PDF متجه** و **SVG متجه** (النصوص محوّلة إلى منحنيات وتُفتح في Illustrator / Inkscape / CorelDraw مع طبقات مسمّاة) + **PNG شفاف 600 DPI**. |
| تعديل مجاني | يمكن تغيير الشكل والألوان والخطوط والمقاس لختم تم شراؤه مجاناً؛ تغيير النصوص أو الشعار يُعدّ ختماً جديداً. |
| حماية المعاينة | المعاينة عليها علامة مائية «ختمي · معاينة» ولا تُزال إلا بعد الدفع. |
| المحفظة | شحن برصيد المكالمات من المدار أو ليبيانا، وخصم قيمة الختم مباشرة من المحفظة. |
| لوحة إدارة | اعتماد / رفض طلبات الشحن، تعديل الأسعار وأرقام الاستقبال ونسبة التحويل، إدارة أرصدة المستخدمين، إحصائيات. |
| واجهة | أسود وأصفر حسب الشعار، عربي (RTL) وإنجليزي، متجاوبة مع الجوال، قابلة للتثبيت كتطبيق (PWA). |

## 💰 التسعير

يظهر السعر للعميل مباشرة في المعاينة قبل الشراء:

- **ختم نصي فقط** = عدد الحروف × سعر الحرف
- **ختم بأيقونة أو شعار + نص** = عدد الحروف × سعر الحرف + رسوم الأيقونة (أو رسوم الشعار)

تُعدّ الحروف والأرقام فقط في كل نصوص الختم (لا تُحسب المسافات، التشكيل، التطويل «ـ» أو الرموز).
الأسعار الافتراضية (قابلة للتعديل من لوحة الإدارة): الحرف **0.500 د.ل**، الأيقونة المدمجة **3 د.ل**، شعار العميل **5 د.ل**.

## 📱 شحن المحفظة برصيد المكالمات

1. يختار العميل الشركة (المدار / ليبيانا) ويدخل رقمه والمبلغ.
2. يظهر له رقم ختمي لاستقبال الرصيد ليحوّل إليه عبر خدمة تحويل الرصيد في شركته.
3. يُعتمد الطلب ويُضاف المبلغ للمحفظة بإحدى طريقتين:
   - **يدوياً** من لوحة الإدارة بعد التأكد من وصول التحويل (يمكن تعديل المبلغ المستلم فعلياً).
   - **تلقائياً** عبر Webhook: ثبّت على هاتف الاستقبال تطبيق إعادة توجيه الرسائل (SMS Forwarder) ليرسل رسائل التحويل الواردة إلى:
     `POST /api/webhooks/sms` بالمحتوى `{"secret": "<SMS_WEBHOOK_SECRET>", "from": "...", "message": "نص الرسالة"}`
     يستخرج الخادم رقم المحوِّل والمبلغ ويعتمد الطلب المطابق تلقائياً. تظهر كل الرسائل الواردة في لوحة الإدارة للتأكد من أن صيغتها تُقرأ بشكل صحيح.

- رقم استقبال **المدار** مُعدّ مسبقاً: **0911110588**.
- **ليبيانا** غير مفعّلة حتى تضيف رقم ليبيانا (092 / 094) من لوحة الإدارة أو عبر `LIBYANA_NUMBER`، لأن رصيد ليبيانا لا يمكن تحويله إلى رقم المدار.
- نسبة التحويل الافتراضية 1 (كل 1 د.ل رصيد = 1 د.ل في المحفظة) ويمكن تغييرها لكل شركة.
- التطبيق محلي: يقبل أرقام الهواتف الليبية فقط (091 / 092 / 093 / 094 أو بصيغة ‎+218).

## 🚀 التشغيل

يتطلب **Node.js 20** أو أحدث.

```bash
cd khatmi
```

```bash
npm install
```

```bash
ADMIN_PASSWORD='كلمة-مرور-قوية' KHATMI_SECRET='سر-طويل-عشوائي' npm start
```

ثم افتح `http://localhost:3000` للتطبيق و `http://localhost:3000/admin.html` للوحة الإدارة.

### متغيرات البيئة

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ الخادم (الافتراضي 3000) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة (**غيّرها**، الافتراضية admin1234) |
| `KHATMI_SECRET` | سر توقيع جلسات الدخول (**غيّره**) |
| `ANTHROPIC_API_KEY` | لتفعيل التصميم بالذكاء الاصطناعي عبر Claude (اختياري) |
| `KHATMI_AI_MODEL` | نموذج Claude المستخدم (الافتراضي `claude-opus-5-5`) |
| `MADAR_NUMBER` / `LIBYANA_NUMBER` | أرقام استقبال الرصيد عند أول تشغيل |
| `SMS_WEBHOOK_SECRET` | سر Webhook الرسائل (يُعطّل الـ Webhook إذا كان فارغاً) |
| `KHATMI_DATA_DIR` | مجلد البيانات (الافتراضي `khatmi/data`) |

## ملاحظات قبل الإطلاق

- شركات الاتصالات لا توفّر واجهة برمجية عامة للتحقق من تحويل الرصيد، لذلك يعتمد التحقق على المراجعة اليدوية أو قراءة رسائل SMS على هاتف الاستقبال. راجع صيغة رسائل التحويل الفعلية لكل شركة في سجل الرسائل بلوحة الإدارة.
- التخزين الحالي ملف JSON مناسب للبداية؛ عند زيادة المستخدمين يُنصح بالانتقال إلى قاعدة بيانات (PostgreSQL / SQLite).
- شغّل الخادم خلف HTTPS في الإنتاج.
