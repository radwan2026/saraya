خطوات التشغيل على Netlify:
1) Site configuration → Forms → Enable form detection (تفعيل اكتشاف النماذج).
2) ارفع مجلداً فيه index.html (Deploys → اسحب المجلد). يجب الرفع بعد الخطوة 1.
3) Site configuration → Notifications → Emails and webhooks → Form submission notifications
   → Add notification → Email notification → radzenrad@gmail.com → Form: raffle.
4) جرّب تسجيلاً. التسجيلات تظهر في تبويب Forms → raffle، ويمكن تنزيلها CSV (Download as CSV).
