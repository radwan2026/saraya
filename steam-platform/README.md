# 🔬 STEAM Science Games — منصة التجارب العلمية التفاعلية

منصة ويب عربية (RTL) للصفوف 1–6. فيها **7 تجارب علمية تفاعلية** مبنية على قالب موحّد، بهوية **STEAM science games** (أرجواني + رمادي فاتح).

## التشغيل
لا تحتاج إلى تثبيت أي شيء: افتح `index.html` في المتصفح مباشرة.
أو شغّل خادماً محلياً: `npx serve steam-platform` ثم افتح الرابط.

## الصفحات
| الصفحة | الوصف |
|---|---|
| `index.html` | ملف التلميذ (الاسم والصف)، شبكة التجارب، الأوسمة، الشهادة |
| `experiment.html?id=…` | درس التجربة: مقدّمة مصوّرة ← المختبر والتحدّي ← اختبار سريع ← نشاط منزلي وأمان ← دليل المعلّم والمطوّر |
| `teacher.html` | لوحة المعلّم (الرمز الافتراضي **1234**): مؤشرات الأداء، توصيات تصحيحية، قفل الباراميترات، تثبيت الصف، تصدير CSV/JSON |
| `guide.html` | دليل المحتوى: البنود العشرة لكل تجربة، جاهز للطباعة |

## التجارب
`water-cycle` الدورة المائية · `filtration` ترشيح المياه · `orbit` الجاذبية والمدارات · `density` برج الكثافة · `lungs` الرئتان · `capillary` الخاصية الشعرية · `volcano` البركان

## التكيّف حسب الصف
- **مبسّط (الصفوف 1–2):** أزرار «قليل/متوسط/كثير» بدل المنزلقات، دون أرقام أو رسوم بيانية، مع قراءة صوتية (TTS).
- **قياسي (الصفوف 3–4):** منزلقات وقيم عددية ورسوم بيانية أساسية.
- **متقدّم (الصفوف 5–6):** باراميترات إضافية (كثافة كل سائل، مقاومة المجرى الهوائي، النتح، الفحم النشط…)، متّجهات، ورسوم بيانية تحليلية.

## البنية التقنية
- HTML/CSS/JS عادي مع Canvas 2D، دون مكتبات أو أدوات بناء، ويعمل عبر `file://`.
- `js/core.js`: التخزين (localStorage)، الأصوات (WebAudio مولّدة دون ملفات)، القراءة الصوتية، الرسوم البيانية، حلقة المحاكاة.
- `js/data.js`: كل المحتوى التعليمي. تعديل النصوص والأسئلة يتم هنا فقط.
- `js/sims/*.js`: محاكاة لكل تجربة بواجهة موحّدة: `controls / actions / chartTitle / create(host)`.
- لإضافة تجربة جديدة: أضف عنصراً في `data.js` وملفاً في `js/sims/` بنفس الواجهة، ثم ضمّنه في `experiment.html` و`teacher.html`.

> تُحفظ البيانات في متصفح الجهاز فقط (localStorage). لمشاركة البيانات بين أجهزة الصف يلزم خادم/قاعدة بيانات (خطوة لاحقة).
