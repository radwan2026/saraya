# منصة لجنة الأنشطة — شركة المدار الجديد

منصة لتنظيم **مشاركة الشركة في الأنشطة والمسابقات الخارجية**: متابعة البطولات والمحافل والدوريات خارج الشركة، والفرق والمنتخبات المرشّحة لتمثيلها، واكتشاف المواهب ورعايتها، وتجهيز المشاركين ودعمهم — وفق الميثاق الرياضي الاجتماعي الثقافي واللائحة التنظيمية للجنة.

## التشغيل

يتطلب **Node.js 20** أو أحدث.

```bash
cd activities-platform
npm install
npm start
```

- المنصة: `http://localhost:8080`
- لوحة التحكم: `http://localhost:8080/admin`

عند **أول تشغيل** تُنشأ قاعدة البيانات في مجلد `data/` ويُطبع في الطرفية اسم المستخدم `admin` وكلمة مرور عشوائية — احفظها وغيّرها من زر «🔑 كلمة المرور» في لوحة التحكم. يمكن تحديدها مسبقاً بالمتغير `ADMIN_PASSWORD`.

### نسيت كلمة مرور المدير؟

أوقف المنصة ثم نفّذ في مجلد `activities-platform`:

```bash
npm run reset-password
```

تُطبع كلمة مرور جديدة لحساب `admin` دون حذف أي بيانات، ثم شغّل المنصة بـ `npm start`.

### متغيرات البيئة (اختيارية)

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ الخادم (افتراضي 8080) |
| `DATA_DIR` | مجلد البيانات والصور المرفوعة (افتراضي `data`) |
| `ADMIN_PASSWORD` | كلمة مرور المدير عند أول تشغيل فقط |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `SMTP_SECURE` | لإرسال الشكاوى والأفكار تلقائياً إلى بريد اللجنة. بدونها تُحفظ في المنصة فقط |

> **النسخ الاحتياطي:** كل البيانات في `data/db.json` والصور في `data/uploads/` — انسخ مجلد `data` دورياً.

## ما في المنصة

### الواجهة العامة (للموظفين)
| الصفحة | الوظيفة |
|---|---|
| الرئيسية | الترشح المفتوح، المشاركات قيد الإعداد، الفرق، أحدث الإنجازات، مساحة إعلانية للقرارات والأخبار |
| المشاركات الخارجية | البطولات والمسابقات والمحافل مع الجهة المنظمة والمستوى (محلية/إقليمية/دولية) ومراحلها: باب الترشح مفتوح ← الاختيار والاختبارات ← التجهيز والتدريب ← المشاركة جارية ← منتهية، ونسبة جاهزية التجهيز والنتيجة |
| الترشح لتمثيل الشركة | نموذج المادة (10): الاسم، الرقم الوظيفي، الوصف الوظيفي، الإدارة/المكتب، نوع العقد، الانتساب لنادٍ أو منتخب، الخبرة، والإقرار بالالتزام بالميثاق |
| الفرق والمنتخبات | التشكيلة، المدرب، الإداري، القائد، مواعيد التدريب، والمشاركات المرتبطة بكل فريق |
| سجل المواهب | **نموذج حصر المواهب داخل شركة المدار الجديد** بأقسامه الستة: البيانات الشخصية (الاسم الرباعي، الرقم الوظيفي، العمر، الفرع، الإدارة، الدائرة، القسم، الهاتف، البريد)، المجال/الموهبة، مستوى الموهبة والجهة، الإنجازات، الاحتياجات لتطوير الموهبة، وأي إضافة — مع تحميل النموذج الورقي PDF. القيد اختياري (المادة 30) |
| سجل الإنجازات | الميداليات والنتائج ومكتبة إنجازات الشركة (المادة 89) |
| بطاقة المشارك الرسمي | متابعة حالة الترشح (مقبول / احتياطي / مرفوض مع السبب) وإصدار بطاقة برمز QR للتحقق |
| المسابقة الأسبوعية | أسئلة عن تمثيل الشركة والميثاق بجوائز رصيد |
| التصويت | اختيار البطولات والمحافل التي تشارك فيها الشركة |
| الدعم والشكاوى | طلبات الدعم والتجهيز للمشاركين، والشكاوى والمقترحات برقم تذكرة |
| اللجنة والميثاق | أعضاء اللجنة ومهامهم، ونص الميثاق واللائحة مع البحث والطباعة وتصدير PDF |

### لوحة التحكم (لأعضاء اللجنة)
- **البطولات والمحافل:** إدارة كل مشاركة ومرحلتها والفريق الممثل والميزانية التقديرية، و**قائمة تجهيز** مستمدة من الميثاق (اعتماد الإدارة، إقرار الالتزام، إشعار الرؤساء قبل 7 أيام عمل، نموذج الإيفاد، الكشف الطبي، الزي والمعدات، السفر والإقامة، الميزانية)، وتسجيل النتيجة وتقرير ما بعد المشاركة.
- **الترشيحات:** قبول (يُصدر البطاقة) أو قائمة احتياطية أو رفض مسبّب، وتتبّع إشعار الرئيس المباشر (المادة 58)، والتصدير إلى Excel.
- **الفرق والمنتخبات:** التشكيلة والجهاز الفني واحتياجات الدعم.
- **سجل المواهب:** دراسة كل نموذج وتقييمه (نجوم وملاحظات وبرنامج التأهيل)، والحالة: قيد التقييم / مقيد بالسجل / ترعاه الشركة، و**طباعة الطلب بتخطيط النموذج الرسمي** للأرشفة، و**تصدير حصر المواهب إلى Excel**.
- **صلاحيات مستقلة** لكل عضو: المشاركات والترشيحات، الفرق، المواهب، الأخبار، المسابقة، التصويت، أعضاء اللجنة، الدعم والشكاوى، الإعدادات.

> **الترقية من إصدار سابق:** تُرحَّل البيانات تلقائياً عند التشغيل (المراحل، قوائم التجهيز، الصلاحيات). إن كانت بياناتك تجريبية فقط وتريد المحتوى النموذجي الجديد، احذف مجلد `data` قبل التشغيل (ستظهر كلمة مرور مدير جديدة).

## ملاحظات
- الرقم الوظيفي يُدخله الموظف بنفسه ولا يُتحقق منه مقابل سجل الموارد البشرية؛ يمكن ربط ذلك لاحقاً.
- المحتوى الأولي (أنشطة، أخبار، مسابقة، استطلاع) **تجريبي** للعرض — عدّله أو احذفه من لوحة التحكم. أسماء أعضاء اللجنة مُدخلة، وتبقى الصور والسير الذاتية وتسمية التقسيمات التنظيمية (نائب الرئيس، أمين السر...) لتُضاف من لوحة التحكم.
- عند النشر على الإنترنت استخدم HTTPS عبر خادم وسيط (مثل Nginx) واضبط «الرابط العام» في الإعدادات.
