# منصة لجنة الأنشطة — شركة المدار الجديد

المنصة الإلكترونية للجنة الأنشطة: تسجيل الموظفين في الأنشطة (رياضية، ثقافية، فنية، تطوعية، اجتماعية)، إصدار بطاقات المشاركة، المسابقة الأسبوعية بهدايا رصيد، التصويت على المشاريع والبرامج، نجم الأسبوع، الشكاوى، والميثاق واللائحة التنظيمية — مع لوحة تحكم بصلاحيات لأعضاء اللجنة.

## التشغيل

يتطلب **Node.js 20** أو أحدث.

```bash
cd activities-platform
npm install
npm start
```

- المنصة: `http://localhost:8080`
- لوحة التحكم: `http://localhost:8080/admin`

عند **أول تشغيل** تُنشأ قاعدة البيانات في مجلد `data/` ويُطبع في الطرفية اسم المستخدم `admin` وكلمة مرور عشوائية — احفظها وغيّرها من زر «🔑 كلمة المرور» في لوحة التحكم. يمكن تحديدها مسبقاً بالمتغير `ADMIN_PASSWORD`.

### نسيت كلمة مرور المدير؟

أوقف المنصة ثم نفّذ في مجلد `activities-platform`:

```bash
npm run reset-password
```

تُطبع كلمة مرور جديدة لحساب `admin` دون حذف أي بيانات، ثم شغّل المنصة بـ `npm start`.

### متغيرات البيئة (اختيارية)

| المتغير | الوصف |
|---|---|
| `PORT` | منفذ الخادم (افتراضي 8080) |
| `DATA_DIR` | مجلد البيانات والصور المرفوعة (افتراضي `data`) |
| `ADMIN_PASSWORD` | كلمة مرور المدير عند أول تشغيل فقط |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`, `SMTP_SECURE` | لإرسال الشكاوى والأفكار تلقائياً إلى بريد اللجنة. بدونها تُحفظ في المنصة فقط |

> **النسخ الاحتياطي:** كل البيانات في `data/db.json` والصور في `data/uploads/` — انسخ مجلد `data` دورياً.

## ما في المنصة

### الواجهة العامة (للموظفين)
| الصفحة | الوظيفة |
|---|---|
| الرئيسية | مساحة إعلانية متحركة للإعلانات والقرارات المثبتة، إحصائيات، الأنشطة المفتوحة، المسابقة والتصويت، نجم الأسبوع، الأخبار وروابط التواصل |
| الأنشطة | تصفية حسب النوع، ونموذج تسجيل: الاسم، الرقم الوظيفي، الوصف الوظيفي، الإدارة/المكتب، الهاتف، نوع العقد، الخبرة، والإقرار بالالتزام بالميثاق (المادة 10) |
| بطاقة المشاركة | الاستعلام بالرقم الوظيفي عن حالة الطلبات، وإصدار بطاقة برقم ورمز QR للتحقق، قابلة للطباعة أو الحفظ PDF |
| المسابقة الأسبوعية | أسئلة اختيار من متعدد مع عدّاد تنازلي، مشاركة واحدة لكل رقم وظيفي، وإعلان الفائزين والإجابات بعد الانتهاء |
| التصويت | استطلاعات على المشاريع والبرامج، صوت واحد لكل رقم وظيفي، وإظهار النتائج حسب إعداد اللجنة |
| نجم الأسبوع | عرض النجم الحالي والأرشيف، ونموذج «شاركنا فكرتك» لتقديم الأفكار والبرامج |
| أعضاء اللجنة | الصفة والمهام (من المادة 13 من اللائحة) والسيرة الذاتية لكل عضو |
| الميثاق واللائحة | النص الكامل مع فهرس المواد والبحث، الطباعة، التصدير PDF، وتحميل النسخة الأصلية |
| الشكاوى | تقديم شكوى/مشكلة/مقترح برقم تذكرة، متابعة الحالة ورد اللجنة، وبيانات التواصل (بريد، هاتف، واتساب) |

### لوحة التحكم (لأعضاء اللجنة)
- **صلاحيات مستقلة** لكل عضو: الأنشطة والتسجيلات، الإعلانات والأخبار، المسابقة، التصويت، أعضاء اللجنة، نجم الأسبوع، الشكاوى، الإعدادات. مدير المنصة يملك كل الصلاحيات ويدير المستخدمين.
- مراجعة طلبات التسجيل (القبول يُصدر البطاقة، والرفض يتطلب ذكر السبب)، والبحث والتصدير إلى Excel (CSV).
- إنشاء المسابقات بمحرر أسئلة، وعرض المشاركات، و**السحب العشوائي** على الفائزين من أصحاب أعلى درجة، وتتبع تحويل الرصيد.
- إنشاء استطلاعات ومتابعة النتائج والمصوّتين.
- تحويل فكرة مقدّمة من موظف إلى «نجم الأسبوع».
- **الإعدادات:** بيانات التواصل، روابط فيسبوك وتيك توك وإنستغرام ويوتيوب (تظهر «قريباً» حتى تُضاف)، قائمة الإدارات، والرابط العام المستخدم في رموز QR.

## ملاحظات
- الرقم الوظيفي يُدخله الموظف بنفسه ولا يُتحقق منه مقابل سجل الموارد البشرية؛ يمكن ربط ذلك لاحقاً.
- المحتوى الأولي (أنشطة، أخبار، مسابقة، استطلاع) **تجريبي** للعرض — عدّله أو احذفه من لوحة التحكم. أسماء أعضاء اللجنة مُدخلة، وتبقى الصور والسير الذاتية وتسمية التقسيمات التنظيمية (نائب الرئيس، أمين السر...) لتُضاف من لوحة التحكم.
- عند النشر على الإنترنت استخدم HTTPS عبر خادم وسيط (مثل Nginx) واضبط «الرابط العام» في الإعدادات.
