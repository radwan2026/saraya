# عرض المدار الجديد — رالي تي تي الرياض السياحي

ملفات العرض التقديمي لمشاركة شركة المدار الجديد في رالي تي تي (17 شريحة، أربعة محاور: التجاري، الفني، الإعلامي والإعلاني، الموازنة التقديرية).

- `project/deck.json`: فهرس العرض وترتيب الشرائح والخطوط (Cairo و Tajawal).
- `project/slides/*.html`: شريحة لكل ملف.
- `assets/`: شعار المدار وصور الموقع والمخيم.

القيم بين أقواس مثل `[__]` تُستكمل لاحقاً (الأسعار والكميات ومدة العرض).
