# واجهة أكاديمية ستيم لإثراء العلوم (الإصدار الجديد)

واجهة أمامية حديثة لمنصة **أكاديمية ستيم** بهوية ستيم (الأرجواني + الأزرق الحبري القاتم + لمسات ذهبية)، عربية بالكامل (RTL) ومتجاوبة مع الجوال، مع دمج منصة **ستيمو للبرمجة والروبوتات**.

## الصفحات

| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: الهيرو، محاور STEAM، من نحن والأهداف والرؤية، المستويات، أحدث الدورات، بطاقة ستيمو، لوحة المتصدرين، الألعاب، لماذا ستيم، المؤسسون، انضم للفريق، نموذج التواصل |
| `courses.html` | كتالوج الدورات مع تصفية حسب التصنيف وبحث فوري |
| `videos.html` | معرض الفيديو مع تصفية حسب التصنيف ومشغّل منبثق |
| `simulation.html` | صفحة منصة محاكاة ستيم: المميزات، الدروس العشرة، الباقات، الاشتراك أونلاين، وتفعيل الكود |
| `simulation/` | منصة محاكاة ستيم نفسها (التطبيق) — الدروس الأولى مجانية والباقي بكود تفعيل |
| `simulation/codes.html` | صفحة إدارية لتوليد أكواد التفعيل (غير ظاهرة في القوائم) |
| `stemo.html` | صفحة منصة ستيمو: المنهج (19 درساً / 4 مستويات)، المميزات، الأدوار، المتصدرون، وأزرار الدخول والتسجيل |

## كيف يعمل الدمج

- **الدورات** تُسحب مباشرةً من ووردبريس/LearnPress عبر `wp-json/wp/v2/lp_course` (العنوان والصورة والتصنيف والوصف). أي دورة تُضاف من لوحة تحكم ووردبريس تظهر تلقائياً. إن تعذّر الاتصال تُعرض نسخة احتياطية مدمجة من الدورات الحالية.
- **التسجيل والدخول والملف الشخصي** تبقى على منصة LearnPress الحالية (روابط في `assets/js/config.js`).
- **ستيمو**: بطاقة ورابط وأزرار دخول/تسجيل إلى `https://stemo-coding.pages.dev/`. (لا يمكن تضمين ستيمو داخل إطار iframe لأن المنصة تمنع ذلك بـ `X-Frame-Options: DENY`.)
- **لوحة المتصدرين** تُقرأ من `stemo-coding.pages.dev/api/public/leaderboard` و `schools-leaderboard`.
  ⚠️ يجب إضافة نطاق الموقع (مثل `https://www.steamacademy.ly`) لقائمة CORS في منصة ستيمو (`Access-Control-Allow-Origin`) حتى تظهر النتائج؛ وإلى حين ذلك تظهر بطاقة تدعو لفتح اللوحة على ستيمو.

## معرض الفيديو

يظهر قسم الفيديو في الرئيسية (أحدث 6) وفي صفحة `videos.html`. إذا لم توجد فيديوهات يختفي القسم من الرئيسية تلقائياً.

**بالتحميل:**
- ارفع الفيديو إلى **الوسائط ← أضف جديد** في لوحة ووردبريس، فيظهر في المعرض تلقائياً (الإعداد `videos.wpMedia: true`).
- أو ضع الملف (mp4/webm) في `assets/videos/` وأضف سطراً له في `videos.list` داخل `assets/js/config.js`.

**برابط:** أضف سطراً في `videos.list`:

```js
{ title: "جولة داخل الأكاديمية", url: "https://www.youtube.com/watch?v=XXXXXXXXXXX", category: "عن الأكاديمية" },
```

الروابط المدعومة: يوتيوب (عادي وShorts وyoutu.be)، فيميو، فيسبوك، جوجل درايف (يجب أن يكون الملف مشاركاً للجميع)، أو رابط مباشر لملف فيديو.
الحقول الاختيارية: `category` للتصنيف، `desc` لوصف قصير، `poster` لصورة غلاف.
الفيديوهات الكبيرة يُفضّل رفعها على يوتيوب ووضع الرابط حفاظاً على سرعة الموقع.

## منصة محاكاة ستيم والاشتراك أونلاين

**رحلة الطالب:**
1. يدخل صفحة `simulation.html` (من قائمة «منصاتنا» أو بطاقة المنصة في الرئيسية) ويجرّب أول 3 دروس مجاناً.
2. يختار باقة ويملأ «طلب اشتراك طالب».
3. تؤكد الأكاديمية الاشتراك والدفع، ثم ترسل له **كود تفعيل**.
4. يُدخل الكود في الصفحة أو داخل المنصة (زر «لدي كود تفعيل») فتُفتح جميع الدروس على ذلك الجهاز.

**استقبال الطلبات** (`simulation.subscribeEndpoint` في `config.js`):
- اتركه فارغاً: يُرسل الطلب عبر **واتساب** إن كان `contact.whatsapp` مضبوطاً، وإلا عبر **البريد**.
- أو ضع رابط خدمة نماذج مثل Formspree أو Google Apps Script لتصل الطلبات مباشرة دون تدخل من ولي الأمر.

**إصدار الأكواد:** افتح `simulation/codes.html`، اكتب اسم الطالب واختر المدة، ثم:
- أرسل الكود للطالب (يوجد زر لنسخ رسالة جاهزة).
- ألصق السطر البرمجي داخل `simulation.codes` في `config.js` وارفع الملف للموقع.
- لإلغاء اشتراك: احذف سطر الطالب. الكود المنتهي يُقفل تلقائياً في تاريخه.

**الباقات والأسعار وعدد الدروس المجانية** كلها في `simulation` داخل `config.js` (اترك السعر فارغاً ليظهر «يُحدَّد عند التواصل»).

⚠️ **حدود الحماية:** التحقق من الكود يتم في المتصفح ويُحفظ فيه «بصمة» الكود فقط، وهذا مناسب لموقع ثابت ويمنع الاستخدام العادي، لكنه ليس حماية خادمية: شخص خبير تقنياً يمكنه تجاوزه. للحماية الكاملة والدفع الإلكتروني الآلي يلزم ربط المنصة بحسابات LearnPress في ووردبريس أو بخادم خاص.

## صور ستيمو

ضع صورتي منصة ستيمو في `assets/img/` بالأسماء:

- `stemo-1.webp` — تظهر في بطاقة ستيمو (الرئيسية وصفحة الدورات وصفحة ستيمو)
- `stemo-2.webp` — بانر كبير أعلى صفحة ستيمو

(يقبل أيضاً JPG/PNG بتعديل المسار في `config.js`). إن لم توجد الصور يظهر رسم توضيحي متحرك للروبوت ستيمو بدلاً منها تلقائياً.

## التخصيص

كل الروابط وبيانات التواصل (البريد، الهاتف، واتساب) في ملف واحد: `assets/js/config.js`.
الألوان كلها متغيرات في أعلى `assets/css/style.css`.

## التشغيل والنشر

موقع ثابت لا يحتاج بناء. للتجربة محلياً:

```bash
cd steam-academy && python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. للنشر: ارفع مجلد `steam-academy` كما هو إلى أي استضافة ثابتة (Cloudflare Pages، أو مجلد على نفس خادم steamacademy.ly).
