# ألعاب ستيم — إضافة لعبة جديدة

1. أنشئ مجلداً باسم معرّف اللعبة (إنجليزي بدون مسافات)، مثل `games/planet-race/`، وضع فيه ملفات اللعبة (`index.html` وما يتبعه)، وصورة غلاف `cover.webp` (يفضّل 800×500).
2. أضف هذا السطر داخل `<head>` في ملف اللعبة الرئيسي (يمنع فتحها مباشرة لتجاوز التجربة المجانية):

   ```html
   <script src="../../assets/js/game-guard.js" data-game="planet-race"></script>
   ```

3. أضف كائن اللعبة في `assets/js/config.js` داخل `games.list`:

   ```js
   { id: "planet-race", title: "سباق الكواكب", emoji: "🪐",
     desc: "وصف قصير للعبة.", cover: "games/planet-race/cover.webp",
     url: "games/planet-race/index.html", download: "games/planet-race/planet-race.zip",
     price: 20, ages: "8–12", category: "فلك", previewMinutes: 3 },
   ```

   - `previewMinutes`: مدة التجربة المجانية لهذه اللعبة (الافتراضي في `games.defaultPreviewMinutes`).
   - `download`: اختياري — ملف يُحمَّل بعد الشراء (zip مثلاً).

تظهر اللعبة تلقائياً في صفحة «ألعاب ستيم» وفي قسم الألعاب بالرئيسية. وإن لم تُرفع ملفاتها بعد تظهر صفحتها بحالة «قيد الإطلاق».

## بيع اللعبة

1. يجرّب الزائر اللعبة مجاناً، ثم تُقفل ويظهر له زر الشراء.
2. نافذة الشراء تعرض رقم الحساب المصرفي (`payments.bankAccount`) ونموذجاً لرفع صورة الحوالة. يُرسل النموذج إلى `payments.receiptEmail` عبر خدمة FormSubmit.
   - **أول مرة فقط:** يصل إلى البريد رسالة من FormSubmit لتفعيل النموذج؛ اضغط زر التفعيل فيها، وبعدها تصل كل الحوالات مباشرة.
3. بعد التأكد من وصول المبلغ: افتح `games/codes.html`، ولّد كوداً للمشتري، وألصق السطر في `games.codes` بملف `config.js` وارفعه، ثم أرسل رسالة الرد الجاهزة للمشتري.
4. يُدخل المشتري الكود فتُفتح اللعبة بلا حدود ويظهر زر التحميل.

⚠️ التحقق يتم في المتصفح (موقع ثابت): يمنع الاستخدام العادي، لكن ملفات الألعاب نفسها على الخادم يمكن لشخص خبير تقنياً الوصول إليها. للحماية الكاملة يلزم خادم يتحقق قبل تقديم الملفات.
